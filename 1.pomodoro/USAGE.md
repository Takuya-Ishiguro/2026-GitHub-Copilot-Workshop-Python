# 使用例と設定ガイド

## 📋 基本的な使い方

### 1. アプリケーションの起動
```bash
cd 1.pomodoro
python3 app.py
```

### 2. 初期設定
アプリケーション起動時は以下のデフォルト設定になっています：
- 作業時間: 25分
- 休憩時間: 5分
- テーマ: ライト
- サウンド: 開始音ON、終了音ON、tick音OFF

## 🎯 シナリオ別設定例

### シナリオ1: 短時間集中タイプ
**対象**: 集中力の維持が難しい方、初心者向け

**推奨設定**:
- 作業時間: **15分**
- 休憩時間: **5分**
- テーマ: **フォーカス**（ミニマルで気が散りにくい）
- サウンド: 終了音のみON

**効果**: 短いサイクルで達成感を得やすく、習慣化しやすい

---

### シナリオ2: 標準ポモドーロ
**対象**: ポモドーロテクニックの基本に忠実に実践したい方

**推奨設定**:
- 作業時間: **25分**
- 休憩時間: **5分**
- テーマ: **ライト**
- サウンド: すべてON

**効果**: 最も一般的な設定で、多くの人に効果的

---

### シナリオ3: ディープワーク型
**対象**: 深い集中が必要な複雑なタスクに取り組む方

**推奨設定**:
- 作業時間: **45分**
- 休憩時間: **15分**
- テーマ: **ダーク**（目の疲れを軽減）
- サウンド: 開始音と終了音のみON

**効果**: 長時間の集中とたっぷりの休憩でパフォーマンス最大化

---

### シナリオ4: 夜間作業向け
**対象**: 夜間や暗い環境で作業する方

**推奨設定**:
- 作業時間: **25分** または **35分**
- 休憩時間: **10分**
- テーマ: **ダーク**
- サウンド: tick音OFF（静かな環境維持）

**効果**: 目への負担を軽減し、周囲への配慮も可能

---

## 🔧 カスタマイズのコツ

### 作業時間の選び方
- **15分**: タスクが小さい、または集中力維持が難しい場合
- **25分**: 標準的なポモドーロ、バランスが良い
- **35分**: 少し複雑なタスク、フロー状態に入りやすい
- **45分**: 非常に複雑なタスク、ディープワークに最適

### 休憩時間の選び方
- **5分**: 標準的な休憩、簡単なストレッチや水分補給
- **10分**: 少し長めの休憩、軽い運動や目を休める
- **15分**: しっかりとした休憩、散歩や仮眠も可能

### テーマの選び方
- **ライト**: 明るい環境、日中の作業に最適
- **ダーク**: 暗い環境、夜間や長時間作業に目に優しい
- **フォーカス**: 集中力を高めたい時、ミニマルなデザイン

### サウンドの活用
- **開始音**: タスク開始の合図、切り替えをはっきりさせたい場合にON
- **終了音**: タイマー完了の通知、必須推奨
- **tick音**: 時間の経過を意識したい場合にON（集中を妨げる場合はOFF）

## 📊 効果測定のポイント

以下の指標を記録して、自分に最適な設定を見つけましょう：

1. **完了したポモドーロ数**: 1日あたり何サイクル完了したか
2. **集中度**: 各セッションの集中度（主観評価 1-5点）
3. **タスク完了率**: 予定していたタスクの完了率
4. **疲労度**: 作業後の疲労度（主観評価 1-5点）

### 記録例（テンプレート）
```
日付: 2026-02-24
設定: 作業25分、休憩5分、ライトテーマ
完了ポモドーロ数: 6サイクル
平均集中度: 4.2/5
タスク完了率: 80%
疲労度: 2/5
メモ: tick音をOFFにしたら集中しやすくなった
```

## 💡 Tips

1. **設定は自動保存**: 変更した設定は自動的に保存され、次回起動時に復元されます
2. **一時停止の活用**: 急な用事が入っても一時停止で対応可能
3. **定期的な見直し**: 1週間ごとに設定を見直して最適化しましょう
4. **無理は禁物**: 疲れを感じたら休憩時間を長めに設定しましょう

## 🎓 ポモドーロテクニックの基本ルール

1. **タスクを選ぶ**: 取り組むタスクを1つ決める
2. **タイマーをセット**: 作業時間を設定してスタート
3. **集中して作業**: タイマーが鳴るまで1つのタスクに集中
4. **短い休憩**: タイマーが鳴ったら休憩
5. **繰り返す**: 4サイクル（4ポモドーロ）ごとに15-30分の長い休憩

このアプリケーションは、2と4のステップをサポートし、個人の好みに合わせてカスタマイズできます。
