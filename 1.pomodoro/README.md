# ポモドーロタイマー - 視覚的フィードバック強化版

## 概要

このポモドーロタイマーアプリケーションは、視覚的フィードバックを強化することで、ユーザーの集中力を高めることを目的としています。

## 主な機能

### 1. 円形プログレスバーのアニメーション
- 残り時間に応じて滑らかに減少するアニメーション
- 60FPSで更新される流れるようなビジュアル
- 太く見やすい円弧デザイン

### 2. 色の変化
時間経過に応じて円の色が段階的に変化します：
- **100% - 50%**: 青 (#00d4ff) → 黄 (#ffd700)
- **50% - 0%**: 黄 (#ffd700) → 赤 (#ff4444)

この色の変化により、視覚的に残り時間を直感的に把握できます。

### 3. 背景エフェクト
- **パーティクルエフェクト**: 集中時間中、背景に50個のパーティクルが動き回ります
- **グローエフェクト**: 作業中は円の中心に輝くエフェクトが表示されます
- 休憩時間中はエフェクトが停止し、リラックスできる環境を提供します

## ポモドーロテクニックのタイマー設定

- **作業時間**: 25分
- **短い休憩**: 5分
- **長い休憩**: 15分（4セッションごと）

## 必要な環境

- Python 3.6以上
- tkinter（Pythonの標準ライブラリ）

### tkinterのインストール

#### Ubuntu/Debian
```bash
sudo apt-get install python3-tk
```

#### macOS
macOSのPythonには通常tkinterが含まれています。

#### Windows
公式のPythonインストーラーには通常tkinterが含まれています。

## 使用方法

### 起動方法
```bash
python3 app.py
```

または実行権限を付与して：
```bash
chmod +x app.py
./app.py
```

### 操作方法

1. **開始ボタン**: タイマーを開始します
2. **一時停止ボタン**: タイマーを一時停止します
3. **リセットボタン**: タイマーを初期状態にリセットします

### 使い方のヒント

- 作業セッション中は、パーティクルエフェクトが集中をサポートします
- 色の変化で残り時間を直感的に把握できます
  - 青: まだ十分に時間があります
  - 黄: 半分が経過しました
  - 赤: もうすぐ終了です
- 休憩時間はエフェクトが停止し、リラックスできます

## テスト

基本的な機能テストを実行：
```bash
python3 test_pomodoro.py
```

注: テストの実行にはtkinterが必要です。

- 見やすい時間表示

## 技術的な詳細

### アーキテクチャ

- **PomodoroTimer**: メインタイマークラス
  - タイマーロジック
  - UI管理
  - アニメーション制御

- **Particle**: パーティクルエフェクトクラス
  - 個々のパーティクルの動きを管理
  - 画面端での反射処理

### アニメーション

- **メインループ**: 約60FPS（16msごとに更新）
- **タイマー更新**: 1秒ごと
- **色の補間**: 線形補間でスムーズな色変化

### カラーグラデーション計算

RGB値を時間経過に基づいて線形補間することで、滑らかな色の遷移を実現しています。
