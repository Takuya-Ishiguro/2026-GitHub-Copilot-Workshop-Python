# ポモドーロタイマー - ゲーミフィケーション版

ゲーミフィケーション要素を備えた、モチベーション向上を目的としたポモドーロタイマーアプリケーションです。

## 🎮 主な機能

### 基本機能
- **ポモドーロタイマー**: 25分の作業時間と5分の休憩時間
- **タイマー制御**: 開始、一時停止、リセット

### ゲーミフィケーション要素

#### 1. 経験値（XP）システム
- ポモドーロ完了ごとに100 XPを獲得
- 500 XPごとにレベルアップ
- レベルアップ時には通知表示
- XPバーで進捗を視覚的に確認

#### 2. 達成バッジシステム
実績に応じて様々なバッジを獲得できます：
- **初めてのポモドーロ**: 最初のポモドーロ完了
- **合計10回達成**: 累計10回のポモドーロ完了
- **合計50回達成**: 累計50回のポモドーロ完了
- **今週10回達成**: 1週間で10回のポモドーロ完了
- **3日連続達成**: 3日連続でポモドーロを完了

#### 3. ストリーク表示
- 連続日数のカウント
- 最長記録の保存
- 日々の継続をサポート

#### 4. 統計機能
- **週間統計**:
  - 今週の完了数
  - 達成率（1日1回を目標として計算）
  - 日別完了数のグラフ表示
  
- **月間統計**:
  - 今月の完了数
  - 達成率（1日1回を目標として計算）
  - 平均集中時間

## 🚀 セットアップ

### 必要な環境
- Python 3.12以上
- Flask 3.0.0

### インストール

1. 必要なパッケージをインストール:
```bash
cd 1.pomodoro
pip install -r requirements.txt
```

2. アプリケーションを起動:
```bash
python app.py
```

**開発時のデバッグモード**（本番環境では使用しないでください）:
```bash
export FLASK_DEBUG=true
python app.py
```

3. ブラウザで以下のURLにアクセス:
```
http://localhost:5000
```

## 📊 データ管理

- データベースは自動的に初期化されます

## 🎯 使用方法

1. **タイマーを開始**: 「開始」ボタンをクリックして作業を開始
2. **集中**: 25分間タスクに集中
3. **完了**: タイマーが終了したら自動的にXPとバッジをチェック
4. **休憩**: 5分間の休憩タイマーが自動的に開始
5. **継続**: 休憩後、次のポモドーロを開始

## 📈 モチベーション維持のヒント

- **毎日の目標**: 1日1回のポモドーロを目標に設定
- **ストリークを守る**: 連続日数を維持することでモチベーションアップ
- **バッジコレクション**: すべてのバッジを獲得することを目指す
- **レベルアップ**: レベルを上げることで達成感を味わう

## 🔧 APIエンドポイント

### GET `/api/stats`
ユーザー統計、バッジ、週間/月間統計を取得

### POST `/api/complete_pomodoro`
ポモドーロの完了を記録
- リクエストボディ: `{"duration": 25}` (分)
- レスポンス: XP獲得、レベルアップ情報、新規バッジ
