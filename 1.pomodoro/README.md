# 🍅 ポモドーロタイマー

カスタマイズ可能なポモドーロタイマーアプリケーション

## 機能

### ⏱️ 柔軟な時間設定
- **作業時間**: 15分、25分、35分、45分から選択可能
- **休憩時間**: 5分、10分、15分から選択可能

### 🎨 テーマ切り替え
- **ライトモード**: 明るく見やすいデフォルトテーマ
- **ダークモード**: 目に優しい暗いテーマ
- **フォーカスモード**: ミニマルで集中しやすいテーマ

### 🔊 サウンド設定
- **開始音**: タイマー開始時の音（ON/OFF可能）
- **終了音**: タイマー終了時の音（ON/OFF可能）
- **tick音**: 1秒ごとの音（ON/OFF可能）

### 💾 設定の永続化
- すべての設定は自動的に保存され、次回起動時に復元されます
- 設定ファイル: `settings.json`

## 使用方法

### インストール
必要なライブラリ（標準ライブラリのみ使用）:
```bash
python3 --version  # Python 3.6以上が必要
```

### 実行
```bash
cd 1.pomodoro
python3 app.py
```

### 操作方法
1. **作業時間/休憩時間を設定**: ラジオボタンで好みの時間を選択
2. **テーマを選択**: ライト/ダーク/フォーカスから選択
3. **サウンドを設定**: 各音のON/OFFを切り替え
4. **開始ボタンをクリック**: タイマーを開始
5. **一時停止/再開**: 必要に応じてタイマーを制御
6. **リセット**: タイマーを初期状態に戻す

## テスト

テストを実行するには:
```bash
cd 1.pomodoro
python3 -m unittest test_app.py -v
```

## テストの目的

このアプリケーションは、個人の好みに合わせた設定がユーザー継続率に与える影響を測定することを目的としています。

以下の要素を測定可能:
- 時間設定のカスタマイズによる生産性の変化
- テーマ選択による使用感の違い
- サウンド設定による集中力への影響

## カスタマイズ例

### 短時間集中型
- 作業時間: 15分
- 休憩時間: 5分
- テーマ: フォーカス
- サウンド: 終了音のみON

### 標準ポモドーロ
- 作業時間: 25分
- 休憩時間: 5分
- テーマ: ライト
- サウンド: すべてON

### 長時間集中型
- 作業時間: 45分
- 休憩時間: 15分
- テーマ: ダーク
- サウンド: 開始音と終了音ON

## 技術仕様

- **プログラミング言語**: Python 3.6+
- **GUI フレームワーク**: tkinter（標準ライブラリ）
- **設定保存形式**: JSON
- **スレッド**: タイマー処理は別スレッドで実行
